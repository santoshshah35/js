Sign in to the admin panel

Changes made here are saved straight to the app's files on GitHub, and every phone picks them up the next time Patro opens. No app update is needed.

Getting a token (one time, about 2 minutes)
  1. On github.com, open Settings → Developer settings → Personal access tokens → Fine-grained tokens, and choose Generate new token.
  2. Name it "Patro admin" and pick an expiry (for example 90 days).
  3. Under Repository access choose Only select repositories → santoshshah35/js.
  4. Under Permissions → Repository permissions set Contents: Read and write and Actions: Read and write.
  5. Generate it, copy it (it starts with github_pat_) and paste it above.

Give each manager their own token. Anyone with the token can change the app's content, so don't share it; you can delete it on the same GitHub page at any time.
